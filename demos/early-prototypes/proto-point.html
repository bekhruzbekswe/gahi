      What this shows

      • "These" and "that one" become object IDs you can check before anything runs.
      • Doing a task once gives the agent exact verbs, so it doesn't need to watch a recording.
      • Seeing two prepared outcomes is easier than answering a question in the abstract.

      What could break

      • "That one" can point at the wrong invoice, so the guess must stay visible before the agent acts.
      • One example rarely defines a rule. The agent can learn the wrong condition, so the recipe has to stay readable and editable.
      • A forecast can be wrong, and a tidy comparison can make it look more certain than it is.
